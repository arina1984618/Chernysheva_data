## Установка окружения

1. Создайте виртуальное окружение:
   ```bash
   uv venv
   ``` 

2. Активируйте его:
   ```bash
   source .venv/bin/activate
   ``` 

3. Установите зависимости:
   ```bash
   uv pip install -r requirements.txt
   ```
